Frequently asked questions

Do I need internet or a SIM card to use this?

No. StashPi creates its own WiFi network and serves everything from the microSD card. It's designed to work with zero connectivity of any kind.

How many devices can connect at once?

The WiFi radio and web server can handle several people browsing and searching at the same time. A Raspberry Pi 4 or 5 is recommended if you expect multiple concurrent users.

Can I add my own files?

Yes — plug a USB drive into the Pi and browse it read-only from the library home page, from any connected device. See the how-to-use guide for details.

I already own a Raspberry Pi — do I have to buy another one?

No. Choose "Card only" in step 1 above and tell us which model you own; we'll ship just a pre-flashed microSD card built for that board.

What's covered under warranty?

All hardware we ship — the board, the card, and any add-ons — carries a 1-year warranty against defects. See the full warranty policy.

Is this legal to resell — what about content licensing?

Every included library uses openly licensed or public-domain content (Wikipedia and similar projects under Creative Commons, Project Gutenberg's public-domain texts, etc.), and the software stack is open source. See tech specs for the full stack.
