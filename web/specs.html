Software stack

  • Operating system: a custom, minimal Linux build (Buildroot) — no desktop environment, no unrelated services, just what's needed to serve the library.
  • Content server: kiwix-serve, built on libkiwix and libzim — the same open-source engine that powers offline Wikipedia readers worldwide.
  • Content format: ZIM archives — a compressed, indexed format purpose-built for offline knowledge bases.
  • Networking: the Pi runs as its own WiFi access point (hostapd + dnsmasq), so no external router or internet connection is required.
  • Interface: a custom web UI, reachable from any device's browser — no app to install.

The device software is built on GPL and other open-source components. We provide corresponding source for our modifications on request, consistent with those licenses.

Boot & performance

  • Boots to a usable WiFi network and web server in under a minute.
  • Full-text search is served from a pre-built index on the card — no network round-trip, no external service.
  • Typical indoor WiFi range: roughly 30 feet, similar to a normal home router.
